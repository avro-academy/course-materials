USING GOOGLE COLAB (no install)
  1. Go to colab.research.google.com and sign in with your Google account
  2. File → Upload notebook → choose Python-Foundations-Practice.ipynb
  3. Click a code cell and press Shift + Enter to run it
  For the projects: open a new notebook, paste the .py file into a cell and run it.
  The budget tracker saves budget.csv in Colab's Files panel (the folder icon on
  the left). Colab files are temporary, so download it if you want to keep it.

USING PYTHON ON YOUR OWN COMPUTER
  Install Python 3 from python.org (tick "Add python.exe to PATH" on Windows).
  Open a terminal in the folder and run, for example:
      python projects/quiz-game/quiz.py
  (On a Mac, type python3 instead of python.)
