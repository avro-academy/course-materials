My portfolio: starter files
===========================

This is the starting point for the portfolio website you build in
"Git & GitHub for Beginners" on Avro Academy.

1. Copy this my-portfolio folder somewhere easy to find (like Documents).
2. Open index.html in VS Code and change "Sam Lee" and "Sam" to your own name.
3. Follow Module 2, "Your first commits": open a terminal in this folder and run
       git init
       git add index.html
       git commit -m "Add home page"

You'll add style.css, a .gitignore, a README.md and more sections as you
go through the course. Every step is in the lessons.

(This file is a .txt on purpose, so it doesn't clash with the README.md
you create on GitHub in Module 3. Delete it once you've read it.)
