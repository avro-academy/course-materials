Set up once

git --version
git config --global user.name "Sam Lee"
git config --global user.email "12345678+sam-lee@users.noreply.github.com"
git config --global init.defaultBranch main
git config --global --list

Use your private GitHub email: Settings → Emails → Keep my email addresses private.

Terminal basics

pwdwhich folder am I in?
lslist files
mkdir namemake a folder
cd name / cd ..go in / back up one

No output usually means it worked.

Start a project

mkdir my-portfolio
cd my-portfolio
git init         # creates the hidden .git folder

Never delete or edit .git: it holds all your history.

Save your work: add, then commit

git status                  # what changed?
git add index.html          # stage one file
git add .                   # stage everything here
git commit -m "Add home page"
git commit -am "Fix typo"   # add + commit tracked files

Check git status before git add . so nothing sneaks in.

See history and changes

git log                     # full history (q to quit)
git log --oneline           # one line per commit
git log --oneline --graph   # show branches joining
git diff                    # unstaged changes

In a diff, - lines were removed and + lines were added.

Good commit messages

  • Start with a verb: Add, Fix, Update, Remove
  • Say what changed, in about 50 characters
  • Small and often: one idea per commit
❌ update✅ Add contact section to home page
❌ fixed stuff✅ Fix broken link to projects page

Undo mistakes

git restore index.html          # throw away unsaved edits
git restore --staged draft.txt  # un-stage, keep the file
git merge --abort               # cancel a merge

git restore can't be undone: those edits are gone for good.

.gitignore

.DS_Store
Thumbs.db
draft.txt
.env

Files listed here are never tracked. Never commit passwords, API keys or personal details. Once public, assume it's been copied.

Connect to GitHub and push

git remote add origin https://github.com/sam-lee/my-portfolio.git
git remote -v
git push -u origin main     # first time
git push                    # after that

Passwords don't work for Git. Sign in through the browser: Git Credential Manager (Windows) or gh auth login (Mac/Linux).

Pull and clone

git pull                    # get new commits from GitHub
git clone https://github.com/sam-lee/my-portfolio.git

A clone has the whole history and is already connected as origin.

The daily routine

git pull
# ... work on your files ...
git status
git add .
git commit -m "Describe the change"
git push

Branches

git branch                  # list (* = current)
git switch -c add-projects  # create and move to it
git switch main             # move back
git merge add-projects      # bring work into main
git branch -d add-projects  # delete when merged
git push -u origin add-contact # share a branch

Name branches with dashes: add-contact-page, fix-mobile-menu.

Merge conflicts

<<<<<<< HEAD
  <p>Your branch's version</p>
=======
  <p>The incoming version</p>
>>>>>>> new-intro
  1. Decide what the line should say
  2. Delete all three marker lines
  3. Save, git add, git commit

VS Code offers Accept Current / Incoming / Both. Fewer conflicts: pull often, keep branches short.

Pull requests

  1. Push a branch, then Compare & pull request
  2. Check base: main ← compare: your-branch
  3. Title + description: what, why, how to check
  4. Review in Files changed: Comment, Approve or Request changes
  5. More commits to the branch update the PR
  6. Merge pull request → delete branch → git switch main + git pull

Write Fixes #3 in a PR to close issue 3 when it merges.

Contributing to other projects

  • Fork → clone your fork → branch → push → PR to the original
  • Read README and CONTRIBUTING first
  • Look for good first issue; comment before big work
  • Small, focused PRs; be patient and kind

GitHub Pages

  • Repo → Settings → Pages → Deploy from a branch → main, / (root) → Save
  • Site: https://username.github.io/my-portfolio/
  • Repo named username.github.io → https://username.github.io
  • Home page must be index.html; file names are case-sensitive
  • Not working? Check the Actions tab

Stay safe

  • Turn on two-factor authentication; keep recovery codes safe
  • Use your private noreply email for commits
  • No phone, address or school on your profile
  • Everything in a public repo is public

Apps that run Git for you

VS Code Source Control panel: stage (+), commit, Sync Changes. GitHub Desktop: commit, history, Push origin. They run the same commands underneath.
