All shortcutsCtrl + / · Mac Cmd + /

On a Mac, use Cmd for Ctrl and Option for Alt.

Everyday editing

Undo / RedoCtrl + Z / Ctrl + Y
Mac redo: Cmd + Shift + Z
Select allCtrl + A
Copy / Cut / PasteCtrl + C / X / V
Paste plainCtrl + Shift + V
FindCtrl + F
Find and replaceCtrl + H · Mac Cmd + Shift + H

Select: double-click a word, triple-click a paragraph, Shift + arrows to stretch.

Text formatting

Bold / Italic / UnderlineCtrl + B / I / U
Clear formattingCtrl + \
CapitalsFormat → Text → Capitalisation
Copy formattingPaint format (paint roller): double-click to use it many times

Body text: one clear font (Arial, Roboto, Calibri) at 11 or 12 pt. Decorative fonts only for short headings.

Styles and headings

Heading 1, 2, 3Ctrl + Alt + 1, 2, 3
Normal textCtrl + Alt + 0
Change a style everywhereFormat the heading, then Styles → Heading 1 → Update to match

Use Title for the name, headings for sections. They build the outline and the table of contents.
