The RAG pipeline

1. LoadText out of PDF, Word, Markdown, with source + page
2. ChunkPieces about one thing, split at headings
3. IndexEmbed each chunk, store with metadata
4. SearchMeaning + keywords, filtered by metadata
5. AnswerTop chunks in the prompt, cite them, or say "I don't know"
6. MeasureEvaluation sets for search and for answers

Drop lines that are on every page (running headers and footers) and page numbers. Scanned PDFs have no text: they need OCR. Always look at the extracted text.

Chunking

def fixed_chunks(text, size=150, overlap=30):
    words = text.split()
    step = size - overlap
    return [" ".join(words[i:i + size])
            for i in range(0,
                max(len(words) - overlap, 1), step)]

HEADING = re.compile(
    r"^\d+(\.\d+)*\.?\s+[A-Z].{2,60}$")

Split at headings first, then by size only if a section is long. Start every chunk with its heading, and carry the heading over a page break. 100–300 words is a good start: smaller = sharper matches, bigger = more context.

Metadata and versions

Store source, page, section, plus what the text doesn't say: title, updated, current, audience. Old versions: remove them, or mark current: False and filter. Who-can-see-what is a filter in code, never a request to the model.

Keyword search (BM25)

from rank_bm25 import BM25Okapi
bm25 = BM25Okapi([words(t) for t in texts])
scores = bm25.get_scores(words(question))

Rare shared words score most. Drop stop words ("how", "do", "I"). Great for names, codes, numbers; blind to paraphrases ("lunch" vs "meal break").

Hybrid: Reciprocal Rank Fusion

fused = {}
for results in (vector_top20, keyword_top20):
    for rank, c in enumerate(results, start=1):
        e = fused.setdefault(c["id"], {**c, "score": 0})

Uses positions, not scores, so different scales don't matter.

Measuring search

Eval setReal questions + where the answer is (file > section)
hit@kHow often a right section is in the top k
MRRAverage of 1/rank: 1, ½, ⅓…

Run it after every change. Read every failure: sometimes the test is wrong. Keep some questions you never tune on.

Read the citations back and drop numbers that don't exist. Don't let the model do maths or pick table rows unchecked: use a tool. Documents can contain instructions (indirect prompt injection): control what gets indexed, and never let a document assistant take actions.

Checking answers

For each question: does the answer contain the key fact, and cite a place where it really is? For questions the documents can't answer: does it say so? Bigger projects add an LLM judge and people reading samples.

Keeping it up to date

RebuildSimple; fine for hundreds of documents
IncrementalStore a hash or modified time; re-embed only changes, delete removed files
ScheduleNightly, or when a file is saved
RetireMark old versions current: False
