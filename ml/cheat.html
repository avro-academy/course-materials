The kinds of machine learning

Regressionpredicts a number (customers on Saturday)
Classificationpredicts a category (will they come back?)
Clusteringfinds groups nobody named (kinds of customers)

Supervised = examples come with answers (regression, classification). Unsupervised = no answers (clustering).

Overfitting

Great on training data, much worse on test data = it memorised the noise. Fixes: simpler models (max_depth, min_samples_leaf), forests, more data.

Classification scores

from sklearn.metrics import (
    accuracy_score, confusion_matrix,
    classification_report)
chance = model.predict_proba(X_te)[:, 1]
send = chance < 0.3    # your cut-off
Precisionwhen it says yes, how often is it right?
Recallof the real yeses, how many did it find?

Compare with always guessing the most common answer. Pick the cut-off from what each kind of mistake costs.

Scaling and pipelines

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import \
    StandardScaler
model = make_pipeline(StandardScaler(),
                      LogisticRegression())
from sklearn.compose import \
    make_column_transformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import \
    OneHotEncoder
prep = make_column_transformer(
  (SimpleImputer(strategy="median"),
   ["max_temp"]),
  (OneHotEncoder(handle_unknown="ignore"),
   ["day_of_week"]),
  remainder="passthrough")
model = make_pipeline(prep,
    RandomForestRegressor())
