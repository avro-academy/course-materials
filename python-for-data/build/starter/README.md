# Python for Data: starter files

Avro Academy · Python for Data: Clean, Analyse and Visualise

## What's here
- `data/cafe_sales_2025.csv` – a year of Corner Café sales, messy on purpose (duplicates, blanks, spelling and price-format problems, one typo).
- `data/cafe_sales_2025_clean.csv` – the same data after the Module 3 cleaning script.
- `data/products.csv` – cost price per item (for profit in Module 4).
- `data/rosters/` – four weekly staff rosters (Module 6).
- `notebooks/` – one notebook per module plus the capstone. Exercises have empty cells for you.
- `solutions/` – worked answers. Try first, peek later.
- `scripts/` – `clean_sales.py` (Module 3) and `roster_report.py` (Module 6).

## Getting started
- **Google Colab:** open a notebook (File > Upload notebook), upload this zip file to the Files panel, then run the first cell. It unzips everything and prints "All files found!".
- **Your own computer:** unzip, open the folder in Jupyter or VS Code and run the notebooks from `notebooks/`. You need `pandas` and `matplotlib` (`pip install pandas matplotlib`).
