Select and filter

df["item"]                      # a Series
df[["date", "item"]]            # a DataFrame
df[df["quantity"] >= 4]
df[(df["staff"] == "Sam") & (df["payment"] == "Cash")]
df[(a) | (b)]                   # or
df[df["category"].isin(["Coffee", "Tea"])]
df[df["item"].str.contains("latte", case=False)]
df.loc[df["quantity"] > 10, ["order_id", "item"]]

Wrap each condition in brackets. & = and, | = or, ~ = not.

Clean: text and types

s = df["unit_price"].str.replace("$", "", regex=False)
df["unit_price"] = s.astype(float)
df["item"] = df["item"].str.strip().str.capitalize()
df["payment"] = df["payment"].str.title()
df["date"] = pd.to_datetime(df["date"], format="%d/%m/%Y")
df["quantity"] = df["quantity"].astype(int)

%H:%M24-hour time

Clean: gaps, duplicates, save

df = df.drop_duplicates()
df = df.dropna(subset=["quantity"])
df["payment"] = df["payment"].fillna("Unknown")
df = df[df["quantity"] != 120]   # typo, checked
df.to_csv("clean.csv", index=False)

Honest charts

  • Bars start at zero
  • Title says what and when
  • Label axes, with units
  • Say what was removed in cleaning
  • No cherry-picked periods
  • Compared to what? (shifts worked, days open)
