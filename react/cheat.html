Props and TypeScript

type Props = { job: Job; onEdit?: (id: string) => void };
export const STATUSES = ["Saved", "Applied"] as const;
type Status = (typeof STATUSES)[number];
type JobInput = Omit<Job, "id">;
type Errors = Partial<Record<keyof JobInput, string>>;

Props are read-only. children = what's between the tags.

State

const [search, setSearch] = useState("");

onClick={handle}     // ✅ pass the function
onClick={handle()}   // ❌ runs it every render

Hooks: top level only, never in if or loops. Calculate what you can, don't store it.

Update without changing

AddsetJobs([job, ...jobs])
Change onejobs.map(j => j.id === id ? { ...j, status } : j)
Removejobs.filter(j => j.id !== id)
One fieldsetJob({ ...job, [field]: value })

Lift state up to the closest shared parent; pass data down, functions up. Change a key to reset a component.

  e.preventDefault();

Effects

useEffect(() => {
  document.title = `Job Tracker (${jobs.length})`;
}, [jobs.length]);      // [] = once · none = every render
useEffect(() => {
  let ignore = false;
  fetch("/tips.json").then((r) => r.json()).then((d) => { if (!ignore) setTips(d); });
  return () => { ignore = true; };   // cleanup
}, []);

Plan for loading, error and done. StrictMode runs effects twice in development.
