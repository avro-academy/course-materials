JOB TRACKER: starter files
Avro Academy · React Foundations: Build a Job Application Tracker (React 19)

Each folder is a complete, working app at the end of one module:

  step-1-start        Module 1  Your first component
  step-2-components   Module 2  Types, StatusBadge, JobCard, a list of sample jobs
  step-3-state        Module 3  Search, status filter, change a job's status
  step-4-forms        Module 4  Add and edit jobs with a checked form
  step-5-effects      Module 5  Saved in the browser (localStorage), tip of the day (fetch)
  step-6-router       Module 6  Pages with React Router, filters in the address
  step-7-context      Module 7  useReducer and context (works the same as step 6)
  step-8-final        Module 8  20 automated tests, vercel.json for deploying

RUN ONE
  You need Node.js 22.22 or newer (nodejs.org, LTS version).
  cd step-8-final
  npm install        (once per folder)
  npm run dev        then open http://localhost:5173   (Ctrl + C stops it)

  npm run lint       look for mistakes
  npm test           run the tests (step 8)
  npm run build      the production version, in dist/
  npm run preview    check the build at http://localhost:4173

Your jobs are saved in your own browser only. The sample jobs are made up.
