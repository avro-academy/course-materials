Import and clean

.import --csv everyday-2026-01-to-02.csv raw_jan_feb
-- every column is TEXT: fix it on the way in
INSERT OR IGNORE INTO transactions (day, description, amount, balance)
SELECT substr(Date, 7, 4) || '-' || substr(Date, 4, 2) || '-' || substr(Date, 1, 2),
       Description,
       CAST(replace(Amount, ',', '') AS REAL),
       CAST(replace(Balance, ',', '') AS REAL)
FROM raw_jan_feb
ORDER BY rowid DESC;      -- oldest first
SELECT changes();         -- rows the last statement changed

Duplicates: UNIQUE (day, description, amount, balance) + INSERT OR IGNORE. Date, shop and amount alone can match two real purchases.

⚠️ Foreign keys: off by default

PRAGMA foreign_keys = ON;   -- every connection
PRAGMA foreign_keys;        -- 1 = on, 0 = off
category TEXT NOT NULL REFERENCES budgets (category)

ALTER TABLE can add, rename and drop columns, but not add rules: make a new table, copy, drop, rename.

Categorise with rules

UPDATE transactions
SET category = (
  SELECT r.category FROM rules r
  WHERE transactions.description LIKE r.pattern
  ORDER BY r.priority LIMIT 1
)
WHERE category IS NULL;

A join can use any condition: JOIN rules r ON t.description LIKE r.pattern

Reports

SELECT strftime('%Y-%m', day) AS month,
       round(sum(CASE WHEN amount > 0 THEN amount ELSE 0 END), 2) AS money_in,
       round(sum(CASE WHEN amount < 0 THEN -amount ELSE 0 END), 2) AS money_out
FROM transactions GROUP BY month;

-- budget: date condition in the ON keeps empty categories
FROM budgets b LEFT JOIN transactions t
  ON t.category = b.category AND t.day BETWEEN '2026-03-01' AND '2026-03-31'

Back up and share

.backup budget-backup.db
VACUUM INTO 'budget-copy.db';
sqlite3 budget.db .dump > budget.sql

No password on a SQLite file: keep it as safe as your bank statements.

SQLite or PostgreSQL?

SQLite: one app or person, one device, zero setup, a file you can send. PostgreSQL: many users writing at once, logins and permissions, exact decimals.
