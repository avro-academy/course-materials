# JavaScript for Beginners: starter files

Starter files for the Avro Academy course **JavaScript for Beginners: Code Your First Web Apps**.

Unzip this folder somewhere easy to find (like Documents), then in VS Code choose
**File → Open Folder…** and pick this `javascript-course` folder.

| Folder | What's in it |
| --- | --- |
| `playground/` | A practice page. Write code in `script.js`, open `index.html` in your browser, and check the console. |
| `exercises/` | Practice tasks for Modules 2 to 6 (`module-2.js` … `module-6.js`). |
| `solutions/` | Worked answers for every exercise. Try the task first! |
| `projects/pay-calculator/` | Project 1: shift pay calculator. `start/` has the HTML and CSS ready for your JavaScript; `finished/` is the complete app. |
| `projects/todo-list/` | Project 2: a to-do list that remembers. `start/` and `finished/` as above. |

## How to run an exercise

Exercises are plain JavaScript files. The easiest way to run one:

1. Open `playground/index.html` in a text editor and change `script.js` to `../exercises/module-2.js`
   (or copy the task into `playground/script.js`).
2. Save, refresh the page in your browser and open the console.

Change it back to `script.js` when you're done.

The pay rates in this course are made-up examples for practice. Real pay rates depend on your award: check fairwork.gov.au.
