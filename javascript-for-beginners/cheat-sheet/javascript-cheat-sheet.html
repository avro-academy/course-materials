Output and comments

console.log("Hello, world!");
console.log(2 + 3);   // 5
// A comment: JavaScript ignores it

Open the console: Ctrl+Shift+J (Chrome/Edge), Ctrl+Shift+K (Firefox), Cmd+Option+J on a Mac. JavaScript is case-sensitive.

Variables

const cafeName = "Corner Café"; // can't change
let customers = 12;            // can change
customers = customers + 1;
customers += 5;  customers -= 2;  customers++;

Use const by default, let when the value changes. Avoid old var. Names in camelCase: hoursWorked, totalPrice.

Types of values

"text" 'text'string
42 4.5number
true falseboolean
[1, 2, 3]array (a list)
{ name: "Sam" }object
undefinedno value yet
NaN"Not a Number"
typeof 42      // "number"
typeof "42"    // "string"

Maths

+ - * /add, subtract, multiply, divide
17 % 5remainder → 2
2 ** 3power → 8
(2 + 3) * 4brackets first → 20
(21.989).toFixed(2)  // "21.99" (text)
Math.round(21.989)   // 22
0.1 + 0.2            // 0.30000000000000004

Round money before you show it.

Strings (text)

const name = "Priya";
`Order for ${name}: ${2 * 4.5}` // backticks

"  Jordan Lee ".trim()   // "Jordan Lee"
"Jordan".length          // 6 (no brackets)
"Jordan".toUpperCase()   // "JORDAN"
"Jordan".toLowerCase()   // "jordan"
"Jordan Lee".includes("Lee") // true
"Jordan Lee".slice(0, 6) // "Jordan"
"Sam".startsWith("S")    // true

Numbers that are really text

Anything from a form or .value is a string.

"7" + 3          // "73" (joins text!)
Number("7") + 3  // 10
Number("hello")  // NaN

Comparisons and logic

=== !==equal / not equal (always 3 =)
> < >= <=greater / less than (or equal)
a && band: both true
a || bor: at least one true
!anot: flips true/false

= puts a value in a variable. === compares.

if / else

if (stock === 0) {
  console.log("Out of stock");
} else if (stock < 5) {
  console.log("Low stock");
} else {
  console.log("In stock");
}

// Ternary: condition ? ifTrue : ifFalse
const msg = hours >= 5 ? "Break" : "No break";

The first true condition runs; the rest are skipped.

Arrays (lists)

const drinks = ["Flat white", "Latte", "Chai"];
drinks[0]              // "Flat white" (starts at 0!)
drinks[drinks.length - 1] // last item
drinks.length          // 3
drinks.push("Mocha")   // add to end
drinks.pop()           // remove from end
drinks[1] = "Iced latte" // replace
drinks.includes("Chai") // true
drinks.indexOf("Chai")  // 2

Loops

// every item
for (const task of tasks) {
  console.log(task);
}
// counting
for (let i = 1; i <= 3; i++) { ... }
// repeat while true
while (stock > 0) { stock--; }

// running total
let total = 0;
for (const h of shiftHours) { total += h; }

A condition that never becomes false = infinite loop. Close the tab and fix it.

Array methods

prices.filter((p) => p < 10)  // keep some
prices.map((p) => p * 1.1)    // change each
names.find((n) => n.startsWith("S")) // first match
scores.forEach((s) => console.log(s))
scores.some((s) => s > 90)   // any? true/false
scores.every((s) => s > 50)  // all? true/false
[...nums].sort((a, b) => a - b) // numbers low→high

filter, map and find give a new result; the original array stays the same.

Functions

function calculatePay(hours, rate) {
  return hours * rate;
}
calculatePay(5, 25)   // 125

// Arrow functions
const double = (n) => n * 2;
const isWeekend = (day) => {
  return day === "Saturday" || day === "Sunday";
};

// Default parameter
function welcome(name = "friend") {
  return `Welcome, ${name}!`;
}

return hands a value back; console.log only shows it. Variables made inside { } only exist there (scope).

Objects

const order = {
  item: "Flat white",
  quantity: 2,
  price: 4.5,
  total() { return this.quantity * this.price; },
};
order.item          // "Flat white"
order["price"]      // 4.5
order.size = "Large" // add or change
delete order.size    // remove
order.total()       // 9 (a method)
order.colour        // undefined

Arrays of objects

const roster = [
  { name: "Sam", day: "Saturday", hours: 5 },
  { name: "Ali", day: "Sunday", hours: 4 },
];
roster.filter((s) => s.day === "Saturday")
roster.find((s) => s.name === "Ali")
roster.map((s) => s.name)  // ["Sam", "Ali"]

JSON

JSON.stringify(obj)  // object → text
JSON.parse(text)     // text → object

Keys and strings in double quotes. No functions, comments or trailing commas.

The DOM: changing the page

<script src="script.js"></script> // just before </body>

const title = document.querySelector("#title"); // id
const msg = document.querySelector(".message"); // class
title.textContent = "Welcome!";
title.style.color = "#1d2b4f";
msg.classList.add("highlight");
msg.classList.remove("highlight");
msg.hidden = true;

const li = document.createElement("li");
li.textContent = "Restock fridge";
list.append(li);

Use textContent, not innerHTML, for anything a user typed.

Events

button.addEventListener("click", () => {
  output.textContent = "Clicked!";
});
input.addEventListener("input", () => {
  console.log(input.value); // always a string
});
form.addEventListener("submit", (event) => {
  event.preventDefault(); // no page reload
});

Common events: click, input, change, submit, keydown.

Saving in the browser

localStorage.setItem("tasks", JSON.stringify(tasks));
let tasks = JSON.parse(localStorage.getItem("tasks")) || [];

One browser, one device, strings only. Never for passwords or private data.

Reading errors

SyntaxErrorcode written wrong: missing bracket or quote
ReferenceErrorunknown name: a typo like consol
TypeErrorwrong kind of value, e.g. null from a wrong id

Routine: read the message → go to the line (and the one above) → check spelling, capitals, () {} [], quotes, commas → change one thing, save, refresh.

Debugging toolkit

  • console.log("hours:", hours, typeof hours)
  • Breakpoints: Sources tab (Debugger in Firefox) → click a line number, or write debugger;
  • Rubber duck: explain your code out loud, line by line
  • Didn't change? Save the file and refresh the page
  • querySelector gives null? Check the id and that the script tag is at the end of <body>

Using AI tools well

  • Ask it to explain code or errors, or for hints rather than answers
  • Test everything: AI code can be wrong or insecure
  • Never paste passwords, keys or private data
  • If you can't explain every line, don't use it.
