What MCP is

HostThe AI app a person uses (Claude Desktop, VS Code, your agent)
ClientThe part of the host that talks to one server
ServerA program that offers capabilities to AI apps
ToolsFunctions the model chooses to call
ResourcesInformation the app reads, by URI
PromptsTemplates the person picks

JSON-RPC messages: initialize, tools/list, tools/call, resources/read, prompts/get. Transports: stdio (the app starts the server) or Streamable HTTP (a URL).

from mcp.server.fastmcp import FastMCP
from mcp.types import ToolAnnotations
mcp = FastMCP("Corner Café")

@mcp.tool(annotations=ToolAnnotations(
    title="Check free tables", readOnlyHint=True))
def booking_times(date: str, people: int,
                  time: str = "") -> str:
    """Check free tables. date is YYYY-MM-DD;
    people is 1 to 8; time is HH:MM or empty."""
    problem = bookings.problem_with(date, people)
    if problem:
        return problem          # a plain message
    ...

if __name__ == "__main__":
    mcp.run()                   # stdio

Name, type hints and docstring become the tool's description and JSON Schema. Check every argument: the model may pass anything.

Annotations (hints, not guarantees)

readOnlyHintOnly reads; changes nothing
destructiveHintMight delete or overwrite
idempotentHintTwice = once
openWorldHintReaches the outside world

For anything that matters, make request tools a person approves, not actions.

A client

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

server = StdioServerParameters(
    command=sys.executable, args=["server.py"])
async with stdio_client(server) as (read, write):
    async with ClientSession(read, write) as s:
        await s.initialize()
        tools = (await s.list_tools()).tools
        r = await s.call_tool("booking_times",
            {"date": "2026-10-31", "people": 4})
        print(r.content[0].text)
        await s.read_resource("cafe://menu")
        await s.get_prompt("reply_to_customer",
                           {"message": "Hi!"})

Clients are async: asyncio.run(main()).

Over HTTP, with a token

class StaffToken(TokenVerifier):
    async def verify_token(self, token):
        if TOKEN and secrets.compare_digest(token, TOKEN):
            return AccessToken(token=token,
                client_id="cafe-staff", scopes=["cafe"])

FastMCP("Corner Café", token_verifier=StaffToken(),
        auth=AuthSettings(issuer_url=...,
            resource_server_url=".../mcp",
            required_scopes=["cafe"]))
mcp.run(transport="streamable-http")  # :8000/mcp

streamablehttp_client(url, headers={
    "Authorization": f"Bearer {token}"})

Token from an environment variable. Always HTTPS. One token per person or app. Public servers: OAuth.

Security

Tool poisoningHidden instructions in tool descriptions
Rug pullsTools change after approval: pin versions
Prompt injectionUntrusted content + tools that act = danger
Least accessFewest tools, folders and permissions

Validate arguments, check permissions in each tool, return no secrets, log tool calls.
