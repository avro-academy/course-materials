Set up and run

# Windows
py -m venv .venv
.venv\Scripts\activate
# Mac / Linux
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
flask --app app init-db
flask --app app run --debug

Open http://127.0.0.1:5000. Ctrl + C stops the server. Activate the venv in every new terminal.

200OK
302Redirect
400Bad request
401 / 403Not logged in / not allowed
404Not found
409Conflict (already taken)
500Server code crashed

Security checklist

  • Passwords: hashed, never stored
  • SQL: ? placeholders, never f-strings
  • CSRF: hidden token in every POST form
  • XSS: let Jinja escape, no | safe on user text
  • Permissions: check on the server, not just hide buttons
  • Redirects: only follow ?next= paths starting with one /
  • Secrets: os.environ.get("SECRET_KEY")
  • Production: debug off, HTTPS on

Go live: PythonAnywhere

  1. Upload app.py, schema.sql, requirements.txt, templates, static
  2. Web tab: Manual configuration, newest Python
  3. WSGI file: add your folder to sys.path, set SECRET_KEY, from app import app as application
  4. Bash console: flask --app app init-db
  5. Reload. Problems? Check the error log
