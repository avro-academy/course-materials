npx create-next-app@latest corner-cafe --yes
cd corner-cafe
npm run dev      # http://localhost:3000
npm run lint

JSX rules

  • Components start with a capital: <MenuCard />
  • One outer element, or a fragment <>…</>
  • className, not class
  • Close every tag: <img />
  • { } puts JavaScript in: {item.name}
{items.map((item) => (
  <MenuCard key={item.slug} item={item} />
))}
{open && <p>Open now</p>}
{open ? <p>Open</p> : <p>Closed</p>}

Server or client?

Server (default)Reads data and secrets, sends HTML only
Client "use client"State, clicks, typing, usePathname()
const [search, setSearch] = useState("");
<input value={search}
  onChange={(e) => setSearch(e.target.value)} />

Keep client components small; pass data in as props.
