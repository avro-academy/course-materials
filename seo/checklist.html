Before you start

  • Pick the page's one main keyword from your keyword map
  • Search it: what kind of pages rank? Match that intent
  • No other page on the site targets the same main keyword

Title tag

  • Unique on every page (never "Home", "Services", "Post")
  • Main keyword near the start, written naturally
  • Brand at the end, after | or –
  • About 50–60 characters
<title>Dog Grooming Geelong |
  Bayside Paws Dog Grooming</title>

Meta description

  • Unique on every page
  • About 120–160 characters
  • What the page offers and why to click: a benefit, a detail (price, place, hours)
  • A call to action ("Book online or call…")
  • Keyword included naturally

Headings

  • Exactly one H1: what the page is about, with the keyword
  • H2s for sections, H3s inside them; no skipped levels
  • Real heading tags, not bold paragraphs

Content

  • The answer is in the first paragraph
  • Specific: prices, suburbs, hours, breeds, how long it takes
  • Enough to be useful (a 30-word page gives Google nothing)
  • Keyword and variations used naturally, never stuffed
  • Shows real experience: tips, photos, the author's name
  • Prices, menus and hours are real text, not an image
  • A clear next step (book, call, see prices)

URL

  • Short, lowercase, words joined with hyphens
  • Describes the page: /prices.html, not /post.html?id=7
  • Changed an old URL? Redirect the old address

Links

  • Key pages linked from the home page
  • Blog posts link to the related service
  • Link text says where it goes ("See our dog grooming prices", not "Click here")
  • No broken links (404s)

Images

  • Descriptive file name: dog-full-groom-clip.webp
  • Alt text describes the image (empty alt="" if decorative)
  • Resized to the size shown; WebP; large images under ~200 KB
  • width and height set
  • loading="lazy" below the fold, never on the top image

Mobile and technical

  • Viewport tag in the <head>
  • Text readable and buttons easy to tap on a real phone
  • Loads over https://
  • Canonical tag points to the page's own address
  • Not blocked by robots.txt or a noindex tag (unless on purpose)
  • In the sitemap
<meta name="viewport"
 content="width=device-width,
 initial-scale=1">

Local business pages

  • Same name, address and phone (NAP) as everywhere else
  • NAP in the footer of every page
  • Areas served named honestly (no copy-paste suburb pages)
  • LocalBusiness structured data on the home page

After you publish

  • Check it in the SEO Lab page checker
  • Test it in PageSpeed Insights (mobile): LCP ≤ 2.5 s, CLS ≤ 0.1
  • URL inspection in Search Console → Request indexing
  • Note the date, and check results in a month
