Chatbot, workflow or agent?

ChatbotAnswers from the prompt. One step
WorkflowFixed steps you design; a model may do some. Predictable, cheap
AgentThe model picks tools in a loop until the job is done. Flexible, slower

Use the simplest thing that works. The model only asks for tools; your code runs them and decides what's allowed.

A graph

from typing import TypedDict
from langgraph.graph import StateGraph, START, END

class Order(TypedDict):        # the state
    items: list[str]
    total: float

def add_prices(order: Order):  # a node
    return {"total": 10.3}     # = changes

graph = StateGraph(Order)
graph.add_node("add_prices", add_prices)
graph.add_edge(START, "add_prices")
graph.add_edge("add_prices", END)
app = graph.compile()
app.invoke({"items": ["flat white"]})
print(app.get_graph().draw_mermaid())

The tool runs again from the start on resume: make what's before interrupt() safe to repeat. Approval = a person says yes or no. Handover = a person takes over.
