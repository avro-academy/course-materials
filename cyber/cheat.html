The basics

Confidentialityonly the right people can see it
Integritynobody can secretly change it
Availabilityit works when it's needed

Defence in depth: stack layers (passwords + MFA + firewall + updates + backups). The law: only test systems you own or have written permission to test.

Passwords

  • Long beats complicated: Kettle-Harbour-Violin-77
  • A different password everywhere (stops credential stuffing)
  • A password manager: Bitwarden, 1Password, Apple, Google, Microsoft
  • Check breaches at haveibeenpwned.com
  • Building a system? Slow hashes only: bcrypt, scrypt, Argon2, PBKDF2. Never MD5 or SHA-256

MFA, strongest first

Passkey / security keycan't be phished
Authenticator appnever approve a login you didn't start
SMS codebetter than nothing (SIM swaps)

Turn it on for email first, then banking and work.

Spotting phishing

  • Urgency, threats, prizes
  • Asks for passwords, codes, bank details, gift cards, new payment details
  • From, Reply-To and links that don't match
  • spf=fail, dkim=none, dmarc=fail in the headers
  • Hover (or press and hold) to see where a link really goes
  • Lookalike letters: real name starts xn--
grep -iE '^(from|reply-to|return-path):' \
  mail.eml
grep -i '^authentication-results' mail.eml
grep -o 'href="[^"]*"' mail.eml

Check through a number or website you already know. Report at scamwatch.gov.au.

Least privilege

# who can be root?
getent group sudo
sudo -l
# folders anyone can change
find /srv /var/www /home -perm -o+w \
  2>/dev/null
sudo chown root:cafeteam /srv/cafe-shared
sudo chmod 770 /srv/cafe-shared
# programs that run as root (setuid)
sudo find / -xdev -perm -4000 -type f \
  2>/dev/null

Patching

sudo apt update && sudo apt upgrade
apt list --upgradable
ls /var/run/reboot-required
apt-config dump | grep Unattended

Patch phones, laptops, routers, plugins too. Replace what no longer gets updates.

Scan and firewall

# from your computer:
nmap 192.168.64.5
# on the server: what's listening?
sudo ss -tlnp
sudo ufw allow OpenSSH     # first!
sudo ufw allow 'Nginx HTTP'
sudo ufw --force enable
sudo ufw status

A secret that might have been seen must be changed.

Logs

journalctl -u ssh --since '1 hour ago' \
  --no-pager | grep 'Invalid user' \
  | awk '{print $(NF-2)}' \
  | sort | uniq -c | sort -rn
journalctl -p warning -b
last

Also /var/log/auth.log and /var/log/nginx/access.log.

fail2ban

# /etc/fail2ban/jail.local
[sshd]
enabled  = true
maxretry = 3
findtime = 10m
bantime  = 10m
sudo systemctl restart fail2ban
sudo fail2ban-client status sshd
sudo fail2ban-client set sshd \
  unbanip 1.2.3.4

Changed files and backups

sha256sum /var/www/html/*.html \
  | sudo tee /root/site.sha256
sudo sha256sum -c /root/site.sha256
# back up, and restore
sudo tar -czf /root/site.tgz -C /var/www html
sudo tar -xzf /root/site.tgz -C /var/www

3-2-1: 3 copies, 2 kinds of storage, 1 offline or immutable. Test restores.

Cross-site scripting

import html
# <script> shows as text:
html.escape(text)

Templates (Flask, React) escape for you. Add a Content Security Policy as a second layer.

# /etc/nginx/conf.d/security.conf
server_tokens off;
add_header X-Content-Type-Options
  "nosniff" always;
add_header X-Frame-Options "DENY" always;
add_header Referrer-Policy
  "strict-origin-when-cross-origin" always;
add_header Content-Security-Policy
  "default-src 'self'" always;

HTTPS everywhere: sudo certbot --nginx.
