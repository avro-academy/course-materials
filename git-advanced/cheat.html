Look inside

git cat-file -t HEAD        # object type
git cat-file -p HEAD        # commit: tree, parent, author
git cat-file -p HEAD^{tree} # files in the snapshot
git cat-file -p HEAD:README.md
cat .git/HEAD               # which branch you're on
git rev-parse main          # full commit ID

HEAD~3Three commits back
main^2Merge commit's 2nd parent

Remotes

git fetch                       # download, don't touch my files
git log --oneline main..origin/main   # what I'd get
git diff main origin/main
git pull --ff-only              # only if it can fast-forward
git config --global pull.ff only

Undo

Shared commitgit revert <id> new commit that undoes it
Last commit, not pushedgit commit --amend -m "…"
git commit --amend --no-edit
reset --soft HEAD~1Un-commit, keep staged
reset HEAD~1Un-commit, un-stage (default)
reset --hard HEAD~1Throw the changes away
git restore fileDiscard uncommitted edits

Reset and amend rewrite history: only on commits you haven't pushed.

Rescue with the reflog

git reflog -10
git reset --hard HEAD@{1}       # go back one move
git branch idea HEAD@{1}        # recreate a deleted branch
git branch idea 8d828c2         # or from the ID

Saves committed work for ~90 days. Can't save changes you never committed.

Rebase

git rebase origin/main          # replay my commits on top
git rebase --continue           # after fixing a conflict + git add
git rebase --abort              # back to how it was
git commit -a --fixup ":/Add holiday rate"
git rebase -i --autosquash origin/main
pickKeep
rewordChange message
squashCombine, edit message
fixupCombine, keep first message
dropDelete

Force-push safely

git push --force-with-lease
  • Never plain --force, never on main
  • "stale info" = someone pushed: git fetch, look, then redo your change
  • Golden rule: don't rewrite commits others have built on
