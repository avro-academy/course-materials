What you've built

Look back at Brightside's list from Module 1.4. You now have:

  • A model test sheet for choosing a model with your own questions
  • A message sorter and a details extractor that return JSON a program can use
  • A lesson-plan generator built on a prompt template
  • Study Buddy: a homework helper with rules, memory, and answers from Brightside's notes with sources
  • A red-team script and an answer checker to test it
  • A booking agent with tools and code-checked rules

What you've learned

  • How generative AI and large language models work: tokens, prediction, training and temperature
  • Kinds of models, closed and open, big and small, and how to compare them fairly
  • Responsible AI principles, the layers that reduce harm, and AI security threats
  • Prompt engineering for apps: system prompts, examples, step-by-step reasoning, templates and structured output
  • Building text, chat, search and RAG apps in Python, and tool use
  • Image generation, designing for trust, no-code tools, agents, fine-tuning and the app lifecycle

Make Study Buddy your own

A finished project you can show is worth more than a certificate alone. Pick one:

  1. Your own notes — point the RAG code at your own study notes, a club's FAQ or a family business's price list. Rewrite the tests in check_answers.py for it
  2. A new tool — give the agent a tool that lists the tutors for a subject, and test that it uses it
  3. A better model — run your answer checker with two other models and record the results in your model test sheet
  4. Safer — add three new red-team attacks, and change the system prompt until Study Buddy resists them

Put it on GitHub with a README that says what it does, how to run it, and what you tested. Our Git & GitHub for Beginners course shows you how.
