Is it right? Test it like software

You can't check every answer by hand, every time you change something. So you write an evaluation set: questions with facts you know the answer must contain, and a program that checks them all. Run it after every change to the prompt, the model or the notes.

module-6/check_answers.py

"""Check Study Buddy's answers against facts we know are right."""
from rag import answer

TESTS = [
    ("How much is a one-on-one lesson?", ["85"]),
    ("Do you charge an enrolment fee?", ["no enrolment fee", "no fee", "there is no", "don't charge"]),
    ("When does term 2 start in 2027?", ["26 april"]),
    ("Who teaches chemistry?", ["okafor"]),
    ("What happens if we cancel with only 2 hours' notice?", ["can't", "cannot", "not be"]),
    ("Do you teach physics?", ["don't", "do not", "not"]),
    ("Can I pay with Bitcoin?", ["9630 4471", "don't know", "not sure"]),
    ("Are you open on Fridays?", ["closed", "not open"]),
]

passed = 0
for question, any_of in TESTS:
    text, sources = answer(question)
    ok = any(word in text.lower() for word in any_of)
    passed += ok
    print(f"{'PASS' if ok else 'FAIL'}  {question}\n      {text[:110]}")
    if not ok:
        print(f"      Sources: {', '.join(sources)}")

print(f"\n{passed} of {len(TESTS)} passed")
  • Each test is a question and a list of words; the answer passes if it contains any of them (in lower case)
  • There's a test for a question the notes can't answer (Bitcoin): passing means admitting it, not inventing a payment policy
  • Failures print their sources, to help find the cause

Find the cause

The cancellation answer says "I don't know", but policies.md was among the sources, so search worked. The notes say "With less than 24 hours' notice the lesson can't be made up or refunded". The model even repeated "less than 24 hours' notice" — it just didn't work out that 2 hours is less than 24. So the problem is in the generate step, and the fix goes in the prompt.

Change the start of SYSTEM in rag.py to:

SYSTEM = """You answer questions from parents and students about Brightside Tutoring.
Use ONLY the notes below. The notes may use different words from the question, so apply
their rules to the person's situation (for example, 2 hours' notice is less than 24 hours).
If the notes don't have the answer, say you don't know and suggest calling (02) 9630 4471.
Keep answers to 3 sentences or fewer.

Limits of word checks

Checking for words is quick and clear, but rough. The Bitcoin answer passes, yet a better answer would say Brightside takes bank transfer or card, which is in the notes. "specialize" slipped in with American spelling. Bigger evaluation sets also:

  • Have a person score a sample of answers each week
  • Use a second model as a judge, with a marking guide ("Is every fact in the answer found in the notes?")
  • Track the pass rate over time, so you notice if a change makes things worse
