What fine-tuning is

Fine-tuning means training an existing model a little more, on your own examples, so it gets better at one job. You start from a model that already knows language, and teach it your style or task with hundreds or thousands of examples of "this input → this ideal output".

Try these first

Fine-tuning takes time, data and skills, and you have to redo it when a better base model comes out. Most problems are solved more cheaply by the steps you already know, roughly in this order:

  1. Better prompts (Module 4) — clearer instructions and examples
  2. A different model (Module 2) — sometimes just a bigger or newer one
  3. Giving it your information with RAG (Module 6) — for facts that change, like prices
  4. Fine-tuning — when the problem is how it answers, not what it knows

When fine-tuning helps

Good reasonsPoor reasons
A consistent style or format that prompts can't hold, like Brightside's report-card wordingTeaching it facts that change, like this term's prices (use RAG)
Making a small, cheap model do one narrow job as well as a big oneYou haven't tried better prompts yet
Prompts have become very long, and cost too much per requestYou have only a handful of examples
A specialised vocabulary or task, like sorting messages into your own 20 categoriesYou want it to "know" your private documents

How it's done

  1. Collect examples — usually as a file with one conversation per line: a prompt and the perfect reply. Quality matters more than quantity; every bad example teaches a bad habit
  2. Split them into training examples and test examples the model never sees in training
  3. Train — with a hosted service's fine-tuning feature, or free tools for open models (popular ones use a method called LoRA, which trains only a small add-on so it fits on one graphics card)
  4. Evaluate against the test examples and your old prompt-only version. Is it actually better?
  5. Deploy and watch it, like any new model

Fine-tuning builds on machine learning ideas like training data, test data and overfitting. Our Machine Learning Basics with Python course explains them.
