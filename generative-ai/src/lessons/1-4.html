Brightside Tutoring

All through this course you'll build AI tools for Brightside Tutoring, a small tutoring centre in Parramatta, NSW (a made-up business, so you can experiment freely). It's run by Priya, a former maths teacher, with five tutors. They teach maths, English and science to students from Year 3 to Year 12, in small groups or one-on-one.

Priya's team is busy. They want AI to help with:

Their problemWhat you'll buildModule
Tutors spend hours writing lesson plansA lesson-plan generator5
Students get stuck on homework at nightStudy Buddy, a homework helper that gives hints, not answers5
Parents ask the same questions again and againStudy Buddy answers from Brightside's own notes, with sources6
Parent emails need sorting and enrolment details typed inA sorter and a details-extractor that output data a program can use4
Booking trial lessons takes several stepsA small agent that checks places and books8

Along the way you'll also decide which model to use (Module 2), and make sure Study Buddy is safe for students (Module 3).

What you need

  • A Windows, Mac or Linux computer with at least 8 GB of memory and about 10 GB of free disk space
  • Python 3.10 or newer and some Python basics: variables, lists, dictionaries, functions and loops. New to Python? Do our free Python Foundations course first
  • A code editor, like VS Code
  • No accounts, no API keys and no money: every model in this course is free and runs on your own computer

Modules 1, 3 and 7 have no code at all, so you can do them on any device.
