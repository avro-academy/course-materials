From chatting to building

A text-generation app is a program that sends a prompt to a model and does something with the reply: shows it, saves it, emails it. Every AI app you'll build in this course has the same three steps:

  1. Build the prompt — from your instructions plus what the user typed
  2. Send it to a model — here, through Ollama on your computer
  3. Use the reply

Your first app

Make sure your virtual environment is on (Module 2.3). Open module-5/first_app.py:

module-5/first_app.py

"""Your first text-generation program: one prompt in, one answer out."""
import ollama

MODEL = "llama3.2"

topic = input("What should the quiz question be about? ")

response = ollama.chat(
    model=MODEL,
    messages=[{"role": "user", "content": f"Write one multiple-choice quiz question about {topic} "
                                          "for a Year 6 student, with four options and the answer."}],
)
print()
print(response["message"]["content"])
  • import ollama loads Ollama's Python library, which talks to the Ollama app running on your computer
  • ollama.chat sends a list of messages to the model and waits for the whole reply. Each message is a dictionary with a role and its content. Here there's just one, from the user
  • The prompt is an f-string, so the user's topic is dropped into the middle of your instructions
  • The reply's text is in response["message"]["content"]
cd module-5
python first_app.py

Result (typing equivalent fractions):

What should the quiz question be about? equivalent fractions

Here's a multiple-choice quiz question about equivalent fractions for a Year 6 student:

Question: Which of the following fractions are equivalent to 1/2?

A) 1/3
B) 2/4
C) 3/6
D) 4/8

Answer: C) 3/6

It works — and it's wrong. B, C and D are all equal to 1/2, but it says only C. If a tutor printed this for a class, students who chose B or D would be marked wrong for a right answer.

This is exactly why apps need more than a one-line prompt: clearer instructions ("exactly one correct option"), testing, a stronger model for maths, and a person checking before anything reaches students. You'll add all of these as the module goes on.

An AI's answer is a little different every time, so yours won't match this.

What else is in the response

The response also holds useful numbers:

print("Tokens in:", response["prompt_eval_count"])
print("Tokens out:", response["eval_count"])

Hosted AI services charge by these counts, so apps often log them to track costs.

Using a hosted model instead

Hosted AI services (OpenAI, Anthropic, Google and others) work the same way: a list of messages in, a reply out. The differences are a different Python library, an API key (a secret password for your account, kept in an environment variable, never in your code) and a bill per token. Everything else in this course carries over.
