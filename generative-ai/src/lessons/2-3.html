Install Ollama

Ollama is a free, open-source app that downloads open-weight models and runs them on your computer. It runs in the background and gives you a terminal command (ollama) and a local API that your Python code talks to. No account, no API key, and nothing you type leaves your computer.

Windows

  1. Go to ollama.com/download and download the Windows installer
  2. Run it. Ollama starts in the background; its llama icon appears in the system tray near the clock
  3. Open a new PowerShell or Terminal window

Mac

  1. Download Ollama for macOS from ollama.com/download, open it and drag Ollama to Applications
  2. Open it from Applications and follow the prompt to install the ollama command
  3. Open Terminal

Linux

Follow the Linux instructions at ollama.com/download; they set Ollama up as a service.

Check it works

ollama --version

Try a model in the terminal

ollama run llama3.2 "Explain homework in one sentence for a Year 3 student."

Result:

Homework is work that you do at home, usually on the same subject you learned in school, to help you understand and remember what you've been taught, and it's usually given to you by your teacher to take home and do at the end of the day.

That's one long sentence, and not really Year 3 words. Small models need clear prompts — you'll fix this kind of thing in Module 4. Run ollama run llama3.2 without a question to chat; type /bye to stop.

An AI's answer is a little different every time, so yours won't match this word for word.

Set up Python

Open the unzipped starter files folder in VS Code (or any editor) and open a terminal there. You need Python 3.10 or newer: check with python --version (on a Mac, python3 --version).

Make a virtual environment (a private set of packages for this project), turn it on, and install Ollama's Python library:

python -m venv .venv
# Mac / Linux
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\activate
pip install -r requirements.txt

The end of what you'll see:

Successfully installed ... ollama-0.6.3 ...

Your prompt now starts with (.venv). Turn it on every time you open a new terminal for the course. On a Mac, make it with python3 -m venv .venv; once it's on, python works.

If a program says Failed to connect to Ollama, Ollama isn't running: start the app. If it says model not found, run ollama pull with that model's name.
