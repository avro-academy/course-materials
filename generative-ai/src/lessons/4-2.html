Zero-shot and few-shot

A zero-shot prompt asks for something with no examples. A few-shot prompt shows two or three worked examples first, so the model copies the pattern. It's one of the most reliable ways to make a small model behave.

Brightside wants to sort parent messages into BOOKING, BILLING, COMPLAINT or OTHER. Open module-4/few_shot.py:

module-4/few_shot.py

"""Zero-shot vs few-shot: show the model examples of the answer you want."""
import ollama

MODEL = "llama3.2"

zero_shot = "Sort this parent message into a category: 'Can Mia move to Thursdays next term?'"

few_shot = """Sort each parent message into one category: BOOKING, BILLING, COMPLAINT or OTHER.
Answer with the category only.

Message: How much is a term of one-on-one English?
Category: BILLING

Message: The tutor was 20 minutes late again today.
Category: COMPLAINT

Message: Can Mia move to Thursdays next term?
Category:"""

for name, prompt in [("Zero-shot", zero_shot), ("Few-shot", few_shot)]:
    reply = ollama.chat(model=MODEL, messages=[{"role": "user", "content": prompt}])
    print(f"--- {name} ---")
    print(reply["message"]["content"].strip())

The zero-shot answer isn't wrong, but it's useless to a program: it made up its own categories and wrapped them in a sentence. The few-shot prompt did three things:

  • Listed the allowed answers
  • Showed examples of the exact format
  • Ended with Category: — a cue that makes the next token the answer

Pick examples that cover different categories, and don't always put the same one last, or the model may just copy it.

Step by step

Models write one token at a time and can't "think" before they start. Asking for the working first gives the model room to reason in its own output, which often makes the final answer better. This is called chain-of-thought prompting.

module-4/step_by_step.py

"""Ask for the working, then check it yourself."""
import ollama

MODEL = "llama3.2"

question = (
    "Brightside charges $45 for a small-group lesson. Siblings get 10% off when both "
    "are enrolled. Two sisters each take 10 lessons. What is the total?"
)

prompts = {
    "Answer only": question + " Reply with the number only.",
    "Step by step": question + " Work it out step by step, then give the total on the last line.",
}

for name, prompt in prompts.items():
    reply = ollama.chat(model=MODEL, messages=[{"role": "user", "content": prompt}],
                        options={"temperature": 0})
    print(f"--- {name} ---")
    print(reply["message"]["content"].strip())

print("--- Checked by Python ---")
print(2 * 10 * 45 * 0.9)

options={"temperature": 0} makes the answers as repeatable as possible (Module 4.3).

python step_by_step.py

Result:

--- Answer only ---
$630
--- Step by step ---
To find the total cost, we need to calculate the cost of one lesson for each sister, then apply the 10% discount for both sisters, and finally multiply by 10 (the number of lessons each sister takes).

1. Cost of one lesson: $45
2. Since both sisters are taking 10 lessons, the total cost for one sister is: $45 x 10 = $450
3. Apply 10% discount for both sisters: 10% of $450 = 0.10 x $450 = $45
4. Subtract the discount from the total cost for one sister: $450 - $45 = $405
5. Since both sisters are taking the same number of lessons, the total cost for both sisters is: $405 x 2 = $810

Total: $810
--- Checked by Python ---
810.0

Asked for just the number, llama3.2 said $630, which is nowhere near. Given room to work, it got $810 — the same model that got $405 in Module 2.4. Step-by-step helps a lot, but it isn't a guarantee.

The rule for apps: if a number matters, have your code calculate it. Use the model to understand the request ("two sisters, 10 lessons each") and Python to do the sum.
