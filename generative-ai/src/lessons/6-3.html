Retrieval-augmented generation

A model doesn't know Brightside's prices, and if you ask, it will happily make some up. RAG (retrieval-augmented generation) fixes that in three steps:

  1. Retrieve: search the notes for the chunks closest to the question (Module 6.2)
  2. Augment: put those chunks into the prompt, with an instruction to use only them
  3. Generate: the model writes the answer from the notes

It's how most business chatbots answer from their own documents. Compared with retraining a model, it's cheap, the information is always up to date (change the notes, rebuild the index), and you can show where each answer came from.

Study Buddy answers from the notes

module-6/rag.py (the first version: the one in the starter files already has the fix from Module 6.4)

"""Study Buddy answers questions about Brightside from its notes, and says where the answer came from."""
import ollama

from search import search

MODEL = "llama3.2"

SYSTEM = """You answer questions from parents and students about Brightside Tutoring.
Use ONLY the notes below. If the notes don't have the answer, say you don't know and
suggest calling (02) 9630 4471. Keep answers to 3 sentences or fewer.

Notes:
{notes}"""


def answer(question):
    results = search(question, k=3)
    notes = "\n\n".join(f"[{c['source']}]\n{c['text']}" for _, c in results)
    reply = ollama.chat(
        model=MODEL,
        messages=[{"role": "system", "content": SYSTEM.format(notes=notes)},
                  {"role": "user", "content": question}],
        options={"temperature": 0},
    )
    sources = sorted({c["source"] for _, c in results})
    return reply["message"]["content"].strip(), sources


if __name__ == "__main__":
    while True:
        question = input("\nAsk Study Buddy (or 'quit'): ")
        if question.strip().lower() == "quit":
            break
        text, sources = answer(question)
        print(f"\n{text}\n\nSources: {', '.join(sources)}")
  • The system prompt is a template: {notes} is replaced with the three closest chunks, each labelled with its file name
  • It gives the model a way out: if the notes don't say, admit it and give the phone number
  • Temperature 0 keeps it close to the notes
  • sources lists the files the chunks came from, without repeats

All three are right, and come from Brightside's own notes. Compare with Module 5.4, where a model with no information invented "free maths places" at the local library.

A note on sources

The last answer lists three files, but only about.md has the opening hours. The list shows which chunks were given to the model, not which one it used. Simple apps accept that. Better ones ask the model to name its source for each sentence, or show only chunks above a minimum score. It's another thing worth testing.

When RAG goes wrong

ProblemCauseFix
"I don't know" when the notes do saySearch didn't find the right chunk, or the model didn't connect the question to itCheck what was retrieved; improve chunks or the prompt (next lesson)
A made-up answerThe model ignored "use only the notes"Stronger instructions, a better model, tests
Out-of-date answersThe index wasn't rebuilt after the notes changedRebuild the index whenever the notes change
Instructions hidden in a documentIndirect prompt injection (Module 3.3)Control who edits the notes
