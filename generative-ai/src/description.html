Understand it, use it well, build with it

Generative AI writes, summarises, answers questions, makes images and writes code — and it's now part of almost every kind of work. This course takes you from how it works to building your own small AI apps, using free models that run on your own computer: no accounts, no API keys and no cost.

You'll build tools for Brightside Tutoring, a (made-up) tutoring centre: a lesson-plan generator, Study Buddy — a homework helper that answers from Brightside's own notes, with sources — and a small booking agent.

What you'll learn

  • How large language models work: tokens, prediction, training and temperature, and why they get things wrong
  • Kinds of models — closed and open, big and small — and how to compare them fairly with your own tests
  • Responsible AI: the principles, the harms to look for, AI security threats like prompt injection, and red-teaming your own app
  • Prompt engineering for apps: system prompts, examples, step-by-step reasoning, templates and JSON output
  • Building text, chat and search apps in Python, tool use, and answers from your own documents (RAG)
  • Image generation, designing AI people can trust, no-code AI, agents, fine-tuning and running an AI app for real

Before you start

Modules 1, 3 and 7 have no code. For the rest you need some Python — variables, lists, dictionaries, functions and loops; our free Python Foundations course covers it all — and a Windows, Mac or Linux computer with at least 8 GB of memory and about 10 GB of free disk space.

How it works

  • 8 modules, 30 lessons, about 9 hours including quizzes
  • Every program and AI reply in the lessons was run for real with the free models you'll use — including the mistakes, so you learn to spot them
  • Starter files with the code for every lesson, a cheat sheet, a quiz after each module and a certificate
