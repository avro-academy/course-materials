The words

LLMPredicts the next token, again and again
ParametersThe billions of numbers a model learned (3B = 3 billion)
TokenA word or piece of one. 100 tokens ≈ 75 words
Context windowHow much it can see at once (Ollama: 4,096 tokens by default)
System promptYour instructions: job, tone, rules
Temperature0 = predictable, ~1 = varied. Low for facts
EmbeddingNumbers describing what a text means
RAGRetrieve notes, add them to the prompt, generate
HallucinationA confident, made-up answer
Prompt injectionA message that tries to override your rules

Python: one question

import ollama
response = ollama.chat(
    model="llama3.2",
    messages=[
      {"role": "system",
       "content": "Be brief."},
      {"role": "user", "content": "Hi!"},
    ],
)
print(response["message"]["content"])
response["prompt_eval_count"]  # in
response["eval_count"]         # out

Roles: system (you) · user (them) · assistant (the model).

def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    sa = math.sqrt(sum(x * x for x in a))
    sb = math.sqrt(sum(y * y for y in b))
    return dot / (sa * sb)

Safe and responsible

SecretsNever in a prompt: assume it can leak
PowersCheck every action in code; a person approves big ones
InputsNo system messages from the browser; limit length
OutputShow it with textContent, never as HTML
HonestySay it's an AI; give a way to reach a person
FactsCheck numbers, names, dates, links
