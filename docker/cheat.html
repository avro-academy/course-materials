The words

ImageA packaged app with everything it needs: the recipe's result
ContainerA running copy of an image, walled off from the rest
DockerfileThe recipe for building an image
LayerOne step's snapshot; layers are cached and shared
RegistryWhere images are shared: Docker Hub, ghcr.io
VolumeStorage Docker keeps, separate from any container
Bind mountA folder on your computer, shared into a container
Tagname:version, e.g. shift-swap:1.0

Containers

docker run -d --name web -p 8080:80 nginx:1.29Start in the background, your port 8080 → container 80
docker run -it --rm python:3.13-slimInteractive; removed when it stops
docker ps · docker ps -aRunning · all, stopped too
docker logs -f webFollow its output (Ctrl+C to stop)
docker exec -it web shRun a command inside (here, a shell)
docker stop web · docker start webStop · start again
docker rm -f webRemove (even if running)
docker inspect webEvery detail, as JSON
--restart unless-stoppedStart it again if it stops

A Dockerfile

FROM python:3.13-slim
ENV PYTHONUNBUFFERED=1
WORKDIR /app
# rarely changes: near the top
COPY requirements.txt .
RUN pip install --no-cache-dir \
    -r requirements.txt
# often changes: near the bottom
COPY . .
RUN useradd --create-home appuser
USER appuser
EXPOSE 5000
HEALTHCHECK CMD python -c "..."
CMD ["gunicorn", "--bind",
     "0.0.0.0:5000", "app:app"]

FROM base · WORKDIR cd · COPY files in · RUN at build · CMD at start. Once a step changes, every step after it runs again. Keep junk and secrets out with .dockerignore.

Images

docker build -t shift-swap:1.0 .Build from the Dockerfile here (don't forget the .)
docker imagesList images and sizes
docker history shift-swapIts layers
docker tag shift-swap:1.0 ghcr.io/you/shift-swap:1.0Another name, for a registry
docker login ghcr.io · docker push … · docker pull …Share and fetch

Use -slim images and pin a version (postgres:18, not latest).

Data and settings

-v shiftdata:/dataAttach a volume (made if missing)
-v "$(pwd):/backup"Bind mount this folder (PowerShell: ${PWD})
-e SECRET_KEY=abc · --env-file .envSettings, one or from a file
docker volume ls · docker volume inspect shiftdataList · details
docker run --rm -v shiftdata:/data --user root shift-swap:1.0 chown -R appuser /dataFix an old volume after switching to a non-root user

Containers are disposable: anything that must survive lives in a volume.

Compose

services:
  web:
    build: .
    ports: ["5000:5000"]
    environment:
      DATABASE_URL: postgresql://
        shiftswap:${POSTGRES_PASSWORD}
        @db:5432/shiftswap
    depends_on:
      db:
        condition: service_healthy
  db:
    image: postgres:18
    volumes:
      - db-data:/var/lib/postgresql
volumes:
  db-data:

(DATABASE_URL is one line in the real file.)

docker compose up -d --buildBuild and start everything
docker compose ps · logs -f webStatus · follow one service
docker compose exec db psql -U shiftswapRun a command in a service
docker compose run --rm web flask --app app init-dbA one-off command
docker compose down · down -vStop · and delete the volumes (data!)

Services find each other by name (db). ${…} comes from .env.

When it goes wrong

port is already allocatedSomething uses that port: -p 5050:5000
Exited straight awaydocker logs name says why
no such tableRun init-db first
readonly databaseThe volume belongs to root: chown it (above)
Can't connect from the browserListen on 0.0.0.0, publish with -p
Changes don't showRebuild, then replace the container
